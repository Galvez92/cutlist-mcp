## Rama `demo-web-docs` — Node alineado con jsdom (fallo reportado en el PR #5)

**Hecho**
- Reproducido el fallo con Node 20.20.2 (imagen `node:20-bookworm-slim`): los workers de
  `demo/tests/app/app.test.js` y `demo/tests/app/modules-panel.test.js` no arrancan
  (`TypeError: Cannot read properties of undefined (reading 'bind')` en

  correr. Causa: `jsdom` 30.1.3 arrastra `undici` 8.12.3, que declara `node >=22.19.0`,
  mientras `engines.node` era `>=20`.

  que declara `jsdom` 30.1.3 (cubre el `undici >=22.19.0`). `package-lock.json` se regeneró
  solo para ese campo (`npm install --package-lock-only`).
- `.nvmrc` nuevo con `22.23.4`: la versión con la que se probó aquí y la que entrega
  `node:22-bookworm-slim` en el compose (línea 22 LTS, ≥ 22.22.2).
- `.github/workflows/ci.yml` nuevo (el repo no tenía CI): `actions/setup-node` con
  `node-version-file: .nvmrc`, luego `npm ci`, `npm test` y `npm run typecheck`.
- `AGENTS.md`: nota de la versión de Node, del fallo con Node 20 y de los tres lugares que hay
  que revisar si cambia `jsdom`.
