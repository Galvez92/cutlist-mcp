# Bitácora 2026-10-28

## Corrida: demo ejecutable (Base44)
- **Rama:** `base44/setup-d8c5e742`
- **Qué se hizo:** el repo sólo tenía memoria, fichas y el fixture. Para poder ver
  algo funcionando se implementó el esqueleto mínimo del alcance del README:
  - `cutlist/`: modelos, motor de nesting por guillotina con kerf, veta y
    búsqueda sobre varias estrategias de orden/corte (`optimizer.py`).
  - `cutlist/importers/cortecloud.py`: lee el JSON real de Cortecloud
    (`{"parts":[...]}`), deduce el tablero del nombre del material
    (`(2500x1830)`, `18 mm`) y conserva cantos `c1/c2/l1/l2`.
  - `cutlist/exporters/`: SVG por hoja y lista de corte CSV.
  - `app/`: API FastAPI (`/api/demo`, `/api/optimize`) y demo web en `web/`
    (kerf, girar piezas, subir JSON, layout SVG, lista de corte, descargas).
  - `docker-compose.base44.yml` + `Dockerfile.base44`: entorno de desarrollo con
    recarga automática en el puerto 3000.
- **Pruebas:** `docker compose -f docker-compose.base44.yml exec -T web python -m pytest -q`
  → 23 pasan (motor, importador contra el fixture, API).
- **Verificado:** la demo carga el escritorio D real (30 piezas, 2 tableros, 55.5 %
  de aprovechamiento), el cambio de kerf y de rotación recalcula, y un JSON
  subido se optimiza y dibuja.
- **Pendientes:** nesting no guillotina, exportación PDF, etiquetas, resto de
  importadores (Promob, OpenCutList, Polyboard, Pro100, DXF), módulos
  paramétricos y servidor MCP. La **veta** no viene en el formato Cortecloud:
  queda *por revisar* y hoy se permite girar las piezas.
