# PRO100 (listado TXT/CSV)

Clave: `pro100` · Dirección: **sólo importar** · Estado: **por revisar**

## Fuentes

- CutList Plus, «Pro100 Export to CutList Plus»:
  <https://cutlistplus.com/Support/CAD/Pro100>
  — PRO100 exporta la lista de piezas como **CSV**; el propio CutList Plus avisa
  que «el archivo exportado por Pro100 no especifica el tipo de material de cada
  pieza» y remite al soporte de PRO100 para los pasos de exportación.
- Guía de usuario en ruso (блог «Полезные советы для тех, кто проектирует в PRO100»):
  <https://sovetpro100.blogspot.com/2016/06/export-spiska-detaley-iz-programmi-pro100-v-raskroy-kuznetsova.html>
  — «Отчёты и расчёты» guarda el listado de piezas en un archivo de texto que otra
  aplicación puede leer (el artículo usa «Раскрой» Кузнецова como destino).

## Uso

```python
from cutlist.formats import importar

lista = importar(texto, "pro100", columnas=("nombre", "cantidad", "largo", "ancho", "espesor"))
lista = importar(texto, "pro100", encabezado=True)   # si el archivo trae cabecera
lista = importar(texto, "pro100")                    # orden por defecto, avisa «por revisar»
```

## Por revisar

- El layout del listado exportado (nombres de columna, orden, separador,
  decimales) no está publicado: sin `columnas=` se usa un orden por defecto que la
  lista marca con aviso.
- El archivo de PRO100 no incluye el tipo de material de cada pieza (limitación
  documentada por CutList Plus): hay que completar el material aparte si el
  listado no lo trae.
- El archivo de proyecto `.pro100` es propietario y no se lee; el camino soportado
  es el listado exportado.
- No se implementa exportación: PRO100 no documenta importar listas de corte
  externas.
