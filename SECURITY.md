# Política de seguridad

## Reportar una vulnerabilidad

Por favor **no abras un issue público** para reportar vulnerabilidades.

Usa el reporte privado de GitHub: en este repositorio ve a
**Security → Report a vulnerability** (o
<https://github.com/Galvez92/cutlist-mcp/security/advisories/new>).
Incluye una descripción, pasos para reproducirlo y el impacto posible.

Responderemos lo antes posible y coordinaremos la corrección y su divulgación
contigo antes de hacerla pública.

## Versiones con soporte

Solo la rama `main` recibe correcciones de seguridad.
